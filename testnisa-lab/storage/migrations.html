当前 schema v2 变化

  • 保留 v1 的 records、settings 对象仓库和既有索引。
  • 为 records 新增非唯一 by_name 索引。
  • 新增 schema_meta，记录当前 schema 版本与已执行迁移。
  • 升级在 IndexedDB versionchange 事务内执行；失败时中止事务，由浏览器回滚本次 schema 变更。

升级保护说明

迁移按版本逐步执行（v0 → v1 → v2），不跳过中间步骤。遇到未知迁移路径、缺少旧对象仓库或升级请求被其他标签页阻塞时，打开数据库会失败并显示错误，不会主动删除或重建旧数据。

自动化测试验证迁移步骤与元数据契约；真实浏览器的升级事务回滚行为仍需浏览器验收。
