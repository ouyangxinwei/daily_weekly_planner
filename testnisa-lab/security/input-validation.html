实验规则

  • 普通文本使用 textContent；复杂节点使用 createElement。
  • 不把用户输入传给 innerHTML、insertAdjacentHTML、eval 或 Function。
  • URL 使用协议白名单，拒绝 javascript:、data: 和凭据。
  • HTML maxlength 只是交互提示，JavaScript 仍需独立校验。
  • Meta CSP 不能完整替代 HTTP 响应头；frame-ancestors 等策略应在托管层设置。
