打开金额实验

实验规则

  • 每次 API 请求显示来源、日期、状态和耗时。
  • 错误响应不伪装成有效数据；失败时保留清晰错误信息。
  • 计算核心使用纯函数，不读写 DOM 或 IndexedDB。
  • 日元默认 0 位小数；美元默认 2 位小数；舍入规则明确为 half-up（恰好一半时远离零）。
  • 实验页面不保存用户输入，不使用第三方分析脚本或外部 JavaScript 库。
