# WIKI-002 实验说明

## 本阶段实现
- Markdown 基础块：标题、段落、无序/有序列表、引用块和围栏代码块。
- 行内格式：粗体、斜体、行内代码。
- Wiki 内链：`[[entry-id]]` 或 `[[entry-id|显示名称]]`，目标使用稳定 ID，不依赖标题。
- 出链、反向链接和未解析链接提示。
- 渲染只通过 DOM 节点、`textContent` 和文本节点构建；不将用户正文交给 `innerHTML`。

## 安全与范围
- 原始 HTML 按普通文本显示，不执行 HTML/脚本。
- 暂不支持 Markdown 图片、原始 HTML、表格、嵌入内容或任意 URL 链接。
- 代码块按纯文本显示。
- 删除目标条目不会改写其他条目正文；引用保留为未解析链接。
- 当前仅为预开发原型，未进行真实浏览器 XSS/交互验收。
