# 慢慢计划网页设计文档

**版本：** V6 · reminders  
**目标：** 在 V4 基础版上增加按当前计划标签批量清空功能。

## 产品范围

用户按每日、每周、每月、每年管理计划。可新增、编辑、完成和删除计划；列表显示当前周期完成进度。无需账号与服务器，数据存在当前浏览器。

不包含云同步、登录、多人共享、提醒、历史周期浏览和自定义类别。

## 页面结构

单页包含品牌与日期、七个周期切换标签（四种普通计划和三种随机临时计划）、搜索与筛选排序工具、完成进度条、当前标签批量清理按钮、计划列表、空状态、新建计划按钮和新增／编辑对话框。列表行显示完成勾选框、标题、分类、星级优先级、可选提醒时间、备注及编辑和删除操作。

## 数据和周期

本地存储键为 `personal-planner:v1`。计划记录包含 ID、标题、备注、周期、分类、星级优先级、创建时间和更新时间；随机临时计划额外保存 `cycleId`。完成记录使用“计划 ID + 周期 + 当前周期标识”区分。每日以本地日期为周期；每周从周一开始；每月和每年按自然周期重置完成进度。普通计划跨周期保留，随机临时计划仅在创建周期有效。

## 验收条件

1. 默认显示每日视图和本地日期。
2. 七种计划视图切换正确，且只显示相应普通或随机临时计划。
3. 新增、编辑、删除和完成状态切换可用。
4. 完成统计即时更新，刷新后数据仍在。
5. 新周期开始后，计划保留而完成状态按新周期重置。
6. 删除前确认；取消不会删除。
7. 页面适配桌面和手机，空状态及存储错误有明确提示。

## 本地数据限制

本地存储只属于当前浏览器配置文件。清理网站数据可能丢失数据；V1 可通过 JSON 文件手动备份和恢复，但不提供自动云端同步。

## V1 JSON 备份

页面提供导出和导入 JSON 入口。导出包括全部计划、完成记录和版本元信息；导入校验 JSON 格式、schema、字段、计划数量及完成记录。导入前展示计划总量和各周期数量，确认后替换本地现有数据；取消或校验失败不会写入。单文件最大 2 MB，最多 5000 个计划。

## V2 分类、搜索和排序

新增／编辑表单增加分类选择：未分类、工作、学习、生活、健康、财务、兴趣。列表工具条提供按名称或备注搜索、分类筛选，以及默认顺序、名称 A–Z、最近添加、最早添加四种排序。筛选和搜索只作用于当前周期；进度按当前可见结果统计。旧记录没有分类时显示“未分类”。JSON 备份保留分类字段。

## V3 星级优先级

新增／编辑计划时可选 1、2、3 星优先级，默认为 1 星。列表使用内嵌 SVG 星形展示，优先级同步写入本地存储和 JSON 备份；旧数据缺少优先级时默认为 1 星。排序增加“高优先级”，按星数从高到低排列。

## V4 随机临时计划

增加每日随机、每周随机和每月随机三个独立视图。新增时可直接选择对应周期，复用普通计划的分类、优先级、备注、搜索、排序、完成和 JSON 备份。临时计划只在创建时所在周期存在，日／周／月周期结束后自动清除；周一开始新周。过期条目在载入时及打开页面期间每分钟清理一次；普通周期计划照常保留，不自动重复。

## V6 提醒与通知

计划表单新增可选日期和时间。用户保存提醒计划时请求浏览器通知权限；授权后，页面打开期间检查到期计划，对未完成计划发送一次通知。提醒时间及已提醒标记随计划保存在本地并包含在 JSON 备份中。旧备份缺少提醒字段时按无提醒处理。页面关闭后不会后台触发。

## V5 批量清理

每个标签提供“清空当前标签计划”和“清空当前标签已完成”按钮。执行前确认；操作只针对当前标签全部计划或当前周期已完成计划，忽略搜索和分类筛选；确认后删除计划与完成历史。无可处理条目时对应按钮禁用。
