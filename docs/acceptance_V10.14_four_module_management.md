- [ ] 首页模块顺序为计划、工作、外语学习、整理。
- [ ] 四个模块切换正常，刷新后恢复上次模块。
- [ ] 计划分类不再包含工作；未分类不能编辑或删除。

- [ ] 旧版无 moduleType 的计划 JSON 仍可导入。
- [ ] Supabase 上传当前模块不会覆盖其他分区；原 organizer 分区保持兼容。

- [ ] Service Worker 缓存升级；页面刷新无错误。
