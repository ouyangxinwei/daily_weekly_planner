# 首页天气看板（V10.39）

- 使用 Open-Meteo Forecast API，无需 API Key。固定东京（35.6762, 139.6503）和横滨（35.4437, 139.6380），不读取浏览器定位。
- 单次多坐标请求，`timezone=Asia/Tokyo`、`forecast_days=2`；当前字段含温度、体感、湿度、降水、WMO 天气代码、风速/风向；逐小时字段含降水、降雨、天气代码和 10 米风速（km/h）。
- 显示当前晴/雨/风标签；未来 12 小时内降水达到 0.1 mm 或风速达到 30 km/h 时显示时间提醒。两天预报用于覆盖跨日时段。
- LocalStorage 键 `planner:weather-dashboard:v1`，缓存 10 分钟。有效缓存下普通刷新不请求；「立即刷新」强制更新。
- 请求超时 8 秒。失败时显示历史缓存并标记「当前为离线缓存数据」；无缓存时显示可重试提示。天气数据独立存储，不进入业务数据或 Supabase 同步。
