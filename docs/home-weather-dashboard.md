# 首页天气看板（V10.40）

- 天气看板放在计划页面最下方，计划、任务和学习相关功能保持首要位置。
- 使用 Open-Meteo Forecast API，无需 API Key。固定东京（35.6762, 139.6503）和横滨（35.4437, 139.6380），不读取浏览器定位。
- 单次多坐标请求，时区 Asia/Tokyo，forecast_days=7；daily 字段包含天气代码、最高/最低气温、最大降水概率、降水总量和最大风速（km/h）。
- 每个城市独立显示七天预报，并按外出适宜度排序：晴朗且降水概率不高于 20%、降水量低于 0.2 mm、最大风速不高于 20 km/h 的日期优先；其次为无明显降水且风速适中的日期；其余日期仍完整展示。
- 保留当前天气摘要、10 分钟 LocalStorage 缓存、立即刷新和离线缓存回退。缓存键升级为 planner:weather-dashboard:v2，避免旧版仅含逐小时数据的缓存被误认为七天预报。
- 天气数据独立存储，不进入计划业务数据或 Supabase 同步。
