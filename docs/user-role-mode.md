# 入口分流与界面模式 — V10.73.0

## 1. 目标

启动时提供两个入口，两个入口都使用现有 Supabase 数据库账号登录：

- **个人入口**：登录后进入简洁界面，专注计划、工作、学习和个人事务。
- **管理员入口**：登录后进入完整界面，显示管理员管理工具、测试画面、账号与同步、仓库管理和系统诊断。

两个入口只控制界面显示，不是账号权限系统；不新增认证方式、数据库角色、RLS 规则或 API 权限。

## 2. 个人界面与管理员界面

| 界面 | 显示内容 |
|---|---|
| 个人界面 | 计划模块、工作区切换、日常学习和个人事务；提供独立退出登录入口 |
| 管理员界面 | 个人界面全部功能，以及测试画面、仓库管理、账号与同步、分类管理、回收站、已归档、计划 JSON 导入/导出、版本记录、运行日志、系统健康检查和自动化测试 |

管理员工具集中在顶部「管理员管理」区域。个人界面隐藏整个管理区域，避免日常使用时出现管理入口。

## 3. 登录与切换流程

```
启动
 ├─ 个人入口 → 现有账号登录 → 个人界面
 │                              └─ 退出登录 → 返回启动入口
 └─ 管理员入口 → 现有账号登录 → 管理员界面
                                └─ 退出登录 → 返回启动入口
```

- 选择入口时，将 `planner:user_role` 设为 `personal` 或 `admin`。
- 登录仍调用现有 `planner_login` 数据库函数；两个入口使用同一认证流程。
- 退出登录清除界面模式，下次回到启动入口重新选择。
- 「退出登录」在个人界面单独显示；账号与同步入口归入管理员管理区域。
- 管理员界面不会因显示更多入口而获得额外数据权限。私有数据仍由原有登录、API 和数据库规则保护。

## 4. 管理员管理区域

- 测试画面
- 仓库管理
- 账号与同步
- 分类管理
- 回收站（显示数量）
- 已归档
- 导出计划 JSON、整体导出 JSON、导入计划 JSON
- 版本与更新记录、运行日志、系统健康检查、自动化测试

## 5. 实现文件

- `index.html`：双入口登录文案、管理员管理区域、个人退出登录入口。
- `entry-flow.js`：个人/管理员入口选择、登录表单文案切换、退出后返回入口。
- `role-control.js`：保存并应用本地界面模式。
- `i18n.js`：中英日入口和管理工具文案。
- `sw.js`：静态资源缓存版本和列表。

## 6. 安全边界

「管理员」只是界面模式名称，不代表服务端管理员身份。任何已能通过现有账号登录的用户都可以选择管理员界面；实际数据权限仍由原有服务端校验决定。不得将界面隐藏当作安全控制。
