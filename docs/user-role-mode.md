# 界面模式（使用身份）选择 — V10.69

> 来源：《慢慢计划 — 用户角色区分功能设计文档 V1.0》（2026-11-26），按 2026-11-26 与用户确认的调整方案实现。

## 1. 定位

- 这是**界面模式开关**（个人用户 = 简洁界面，管理员 = 完整界面），**不是权限控制**。任何登录的人都可以自己选择或切换；被隐藏的功能本身没有任何保护。
- 身份只保存在当前浏览器的 LocalStorage（键 `planner:user_role`，值 `personal` / `admin`），不上传云端、不进入 JSON 备份。
- 如果以后要「按账号区分」，需要由服务器在登录时返回身份（例如用户表增加角色字段），属于另一项需求。

## 2. 显示规则

| 入口 | 个人用户 | 管理员 | 标记 |
|---|---|---|---|
| 版本与更新记录 | 隐藏 | 显示 | `data-admin-only="version"` |
| 运行日志 | 隐藏 | 显示 | `data-admin-only="logs"` |
| 系统健康检查（含 GitHub Pages 部署检查项） | 隐藏 | 显示 | `data-admin-only="health"` |
| 自动化测试 | 隐藏 | 显示 | `data-admin-only="tests"` |
| 仓库管理、testNisa 演练、开发日记、计划/工作/外语/整理/成绩/未来/备忘、个人公司网站、天气与股票看板、账号与同步、导入导出 | 显示 | 显示 | — |

- 设计文档中的「GitHub Pages 部署状态」在应用里不是单独的按钮，而是系统健康检查的一个检查项，随健康检查一起隐藏。
- 仓库管理、testNisa 演练和开发日记是设计文档没有列出的入口，本版保持显示；需要隐藏时只要给按钮加 `data-admin-only="…"`，不用改 JS。
- **没有选过身份时按完整界面显示**（现有用户默认等同管理员）。

## 3. 交互流程

```
登录成功
  ├─ 未选择身份 → 弹出「选择使用身份」对话框
  │    ├─ 选「个人用户」→ 立即隐藏管理类入口
  │    ├─ 选「管理员」→ 显示全部
  │    └─ 按 Esc / 点 × 关闭 → 按「管理员」保存（不打断现有习惯）
  └─ 已选择 → 直接按身份显示

「账号与同步」对话框 → 「切换身份」按钮 → 重新打开选择对话框（标出「当前」）
「账号与同步」→「退出登录」→ 清除身份；下次登录再次提示选择
刷新页面：登录状态本来就不保留（需重新登录），但身份保留，登录后不再提示
```

## 4. 实现

| 文件 | 内容 |
|---|---|
| `index.html` | 启动脚本 `data-workspace-boot` 在首屏绘制前读取身份并设置 `<html data-role>`，避免管理按钮先出现再消失；CSS `html[data-role="personal"] [data-admin-only]{display:none!important}`；四个管理入口加 `data-admin-only`；「账号与同步」加「切换身份」按钮；新增 `<dialog id="role-dialog">`（使用主题颜色变量，深色主题可用，Esc 可关闭） |
| `role-control.js` | 普通脚本（非 ES 模块）。读写身份、更新 `data-role`、监听现有 `planner-auth-change` 事件（登录成功后检查是否需要弹窗）、在「退出登录」按钮上清除身份；暴露 `window.PlannerRole`（`getRole / setRole / clearRole / openRoleDialog`） |
| `i18n.js` | 对话框文案的英文、日文翻译（按中文原句匹配） |
| `sw.js` | 缓存名升到 V10.69，`role-control.js` 加入离线缓存清单 |
| `tests/e2e/helpers.js` | 测试启动时预先写入 `admin`，防止首次登录的选择对话框挡住现有用例 |

不修改数据库、RPC、云端快照、备份格式或任何业务数据。

## 5. 待测试清单（本版未执行，交由测试负责人）

本版按「优先开发」要求只做了语法检查和 CI 静态校验，以下场景尚未在浏览器中验证：

1. **首次登录**：清除 `planner:user_role` 后登录，登录成功后弹出选择对话框；登录页显示期间不弹出。
2. **选择个人用户**：版本与更新记录、运行日志、系统健康检查、自动化测试四个按钮隐藏；其他入口正常可用。
3. **选择管理员**：四个按钮全部显示且可打开。
4. **关闭不选**：按 Esc 或点 ×，按管理员保存；之后登录不再提示。
5. **刷新页面**：重新登录后身份保持，不再弹窗；刷新瞬间管理按钮不闪现（个人用户模式下）。
6. **切换身份**：「账号与同步」→「切换身份」，对话框标出「当前」，切换后界面立即更新。
7. **退出登录**：退出后 `planner:user_role` 被清除；再次登录重新提示。
8. **工作区组合**：在计划 / 外语学习 / 个人公司网站三个工作区下分别检查显示规则；公司网站工作区的「仓库管理」仍显示。
9. **深色 / 浅色主题、手机宽度**：对话框显示正常，两张卡片在窄屏下上下排列。
10. **中英日界面**：对话框文案翻译正确。
11. **离线（PWA）**：离线打开时 `role-control.js` 从缓存加载，功能正常。
12. **现有 E2E**：在 GitHub Actions 上确认现有用例不受选择对话框影响。

建议新增的自动化测试：上述 1–7 的 Playwright 用例，以及检查 `data-admin-only` 标记、启动脚本、CSS 规则和 `sw.js` 缓存清单的静态校验脚本。
