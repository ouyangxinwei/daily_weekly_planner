# 入口分流与界面模式 — V10.71

## 1. 目标

启动时先显示两个入口：

- **个人入口**：进入现有账号登录流程；登录成功后使用个人计划、工作、学习和事务管理功能。
- **管理员入口**：无需登录，直接进入后台运行情况视图。只提供学习阶段所需的运行监控，不提供个人计划、账号资料或公司业务数据编辑。

这不是权限系统，不新增账号角色、认证方式、数据库字段、RLS 规则或 API 权限。

## 2. 管理员监控视图

管理员入口只复用现有只读/诊断界面：

| 项目 | 用途 | 数据边界 |
|---|---|---|
| 系统健康检查 | 本机数据结构、日志存储、PWA、云端连接与 Pages 部署状态 | 不修改业务数据；未登录时跳过需要现有账号凭据的 Supabase 数据检查 |
| 运行日志 | 当前设备日志、警告、错误和执行链路 | 日志保存在本机，不上传云端 |
| 版本与部署 | 当前应用版本、GitHub Pages 部署状态、更新履历 | 读取公开 GitHub 信息 |
| 自动化测试 | GitHub Actions 最近一次自动化测试运行 | 读取公开 Actions 状态 |

管理员入口不会显示个人计划列表、同步、账号设置、仓库清单或公司业务资料。通过此入口无法获得任何额外数据访问权限。

## 3. 交互

```
启动
 ├─ 个人入口 → 现有账号登录 → 个人工作区
 │                 └─ 退出登录 → 返回启动入口
 └─ 管理员入口 → 后台运行监控（无需登录）
                    └─ 返回入口 → 启动入口
```

- 个人入口选择后，在登录前将 planner:user_role 设为 personal，保留 V10.69 的个人简洁界面行为。
- 管理员入口将界面模式设为 admin，但只展示独立监控页面；不会打开个人工作区。
- 两个入口可随时返回并重新选择。
- 进入个人工作区后，仍可通过「账号与同步 → 切换身份」调整个人/完整界面显示；该设置仍只影响显示，不授予权限。
- 退出个人账号会清除本地界面模式，下次回到启动入口重新选择。

## 4. 实现文件

| 文件 | 变更 |
|---|---|
| index.html | 启动选择页、个人登录表单、独立管理员监控页 |
| entry-flow.js | 处理个人/管理员入口、返回与退出后的页面切换；管理员监控按钮复用既有状态对话框 |
| entry-flow.css | 双入口卡片、后台监控布局、移动端适配 |
| role-control.js | 保留 V10.69 本地界面模式和个人/完整界面切换 |
| i18n.js | 新入口与后台监控页面中英日文案 |
| sw.js | 更新缓存版本并缓存入口脚本与样式 |

无 Supabase migration、company-api、RPC、RLS、云端快照或业务数据修改。

## 6. 安全与范围说明

「管理员」只是启动页上的产品入口名称，不代表系统识别或验证了管理员身份。任何访问应用的人都可以打开此只读监控视图。真正需要保护的个人资料、公司业务资料和仓库管理数据仍由原有登录、API 与数据库规则控制。
