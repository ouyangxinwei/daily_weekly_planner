# 个人公司网站开发文档

本目录维护「慢慢计划」内个人公司网站模块的需求、架构决定、实施记录和验收结果。

## 当前状态

- 当前阶段：阶段 1-B（数据库最小实现已完成）
- 项目定位：个人开发练习优先，先实现可用版本，保持结构简单、易修改
- 业务数据：第一版使用一张主要业务表 `company_records`，不同记录类型共用基础字段，差异字段放入 JSONB
- 认证：沿用慢慢计划现有自定义账号认证；下一阶段通过 Edge Function 作为服务端入口
- 文件：后续使用独立私有 Storage Bucket，通过短时签名 URL 上传和下载
- 阶段 1-A：设计基线已完成
- 阶段 1-B：数据库迁移已应用，表、权限、错误密码及基础 CRUD/约束完成最小验证
- 下一阶段：阶段 1-C（Edge Function 业务 API）

## 维护规则

1. 每个阶段的需求、关键决定、实施步骤和验收结果都以 Markdown 文件维护并提交到 GitHub。
2. 重要架构调整记录原因、影响范围和迁移方式，不只修改代码。
3. 只做与当前阶段相称的最小测试；优先尽快交付可用功能，但不能省略关键安全检查。
4. 仅文档变更不提升应用 `VERSION`；只有实际应用功能发布时才更新应用版本及对应变更记录。
5. 数据库迁移、Edge Function 和 Storage 变更必须记录对应 SQL、配置、部署状态及验证结果。
