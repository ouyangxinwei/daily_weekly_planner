# 阶段 1-I-E：任务截止日期快速筛选

## 目标

将任务已有的截止日期转化为日常可用的快速筛选能力，降低查找逾期和近期任务的成本。

## 功能范围

- 逾期任务：截止日期早于浏览器本地今天，且状态不是 `completed`。
- 今日到期：截止日期等于浏览器本地今天。
- 未来 7 天：今天起连续 7 个日历日（包含今天，即今天至第 6 天）。
- 无截止日期：`due_date` 为空或缺失。
- 日期筛选与任务名称搜索、任务状态、所属项目筛选组合生效。
- 对筛选后的完整结果集计算总数并分页；结果集缩小时校正当前页。
- 简体中文、英文和日文文案。

## 技术实现

- 新增纯函数模块 `company-task-date-filter.js`，负责本地日期键和截止日期匹配；用固定日期单元测试覆盖边界。
- 任务列表读取全部 task 记录（按 API 分页拉取），在前端组合应用名称、状态、项目和日期条件，再按 `PAGE_SIZE` 切片。
- 项目和跟进列表保留原有 API 分页行为。
- 任务截止日期筛选仅复用现有 `due_date` 与 `status`，不引入新字段。

## 兼容性与影响边界

- 保留任务新增、编辑、删除、项目关联、项目进度自动联动和关联导航。
- 不修改 Supabase 表结构、迁移、RLS、Edge Function 或生产 `company-api v5`。
- 不改变公司业务记录存储格式、认证和其他 planner 模块。

## 验证

- `node --check company-business.js`
- `node --check company-task-date-filter.js`
- `node scripts/validate-v10.50.mjs`：覆盖逾期（含已完成排除）、今天、7 日边界、无截止日期、空筛选和非法日期。
- Playwright：覆盖全部筛选、组合条件、完整结果分页及已完成逾期排除。是否执行浏览器测试以当前 CI 环境为准；未运行或未通过时不记为通过。
