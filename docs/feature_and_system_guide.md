# 功能与系统说明

本文档按当前产品模块组织，描述系统现有功能和数据边界，不再按 V10.x 版本逐段重复记录。历史需求、影响分析、验收与交付记录见 [开发历史与历史交付档案](development-history.md)。

## 1. 计划工作区

### 1.1 计划管理
- 支持每日、每周、每月、每年等周期计划，并提供相应随机临时计划视图。
- 支持计划新增、编辑、完成状态切换、删除、快速添加、搜索、分类筛选和排序。
- 支持 1–5 星优先级、日期与提醒、参考网站。
- 首页提供星级任务统计和快速定位入口。
- 支持分类管理、归档、回收站、恢复、永久删除和短时撤销。
- 支持分页；搜索、筛选或排序后按界面规则回到第一页。
- 支持当前模块 JSON 备份与恢复，并保留四模块整体 JSON 导出能力。

### 1.2 工作模块
工作事项拥有独立分类和任务状态，可进行记录管理、搜索、筛选、归档、回收站、备份及云端分区管理。

### 1.3 外语任务模块
计划工作区内的外语任务列表与独立外语学习工作区是两套不同功能、不同数据存储，不应混为一谈。

### 1.4 整理模块
用于管理书籍、电子产品、软件/APP、网站等资料。采用独立列表和数据分区，不使用计划周期；支持常规列表管理、分类、搜索、归档、回收站、JSON 备份和云端分区。

## 2. 外语学习工作区

独立的学习工作区包含学习首页、学习内容、练习中心、错题管理、学习记录和数据管理。支持多语言学习内容分类、学习状态、练习与笔记等能力。

- 数据保存在独立的浏览器存储键中，不与计划工作区的外语任务混用。
- 支持 JSON 导入/导出和旧数据格式兼容迁移；导入前校验并要求确认。
- 该工作区不参与计划模块的 Supabase 云端同步和四模块整体备份。
- 中、英、日文独立说明：[中文](language-learning-workspace.md) · [English](language-learning-workspace.en.md) · [日本語](language-learning-workspace.ja.md)。

具体字段、状态迁移和兼容细节以外语学习工作区专项说明为准。

## 3. 成绩与未来工作区

首页提供「成绩」和「未来」相关入口，用于组织个人成果记录与未来规划。它们与周期计划视图分开呈现；具体交互以当前应用为准。

## 4. 个人公司网站工作区

公司网站是慢慢计划中的独立业务工作区，目前包括：

- **客户管理：** 客户列表、搜索、业务类型/状态筛选、分页，以及客户新增、编辑、删除。
- **项目管理：** 项目关联客户，支持搜索、状态筛选、分页和 CRUD。
- **业务跟进：** 跟进记录关联客户，可选关联项目；记录跟进方式、时间、结果、下次跟进日期、备注和处理状态。

数据边界与 API：
- 通过 `company-api` Edge Function 访问 Supabase。
- 客户、项目、跟进记录存放在 `company_records`，使用不同 `record_type` 区分。
- 项目和跟进的关联通过记录关系字段表达；删除存在下游引用的项目时不会自动级联删除。
- 复用慢慢计划当前登录会话；不在前端持久化密码或 service-role 密钥。
- 公司业务数据与计划模块 LocalStorage、JSON 快照及云端同步分区隔离。

专项文档：[公司网站阶段文档](company-website/README.md)。

## 5. 首页天气看板

首页显示东京与横滨的天气信息，使用 Open-Meteo，不要求 API Key。数据有独立缓存和离线回退，不进入计划业务数据或 Supabase 同步。详细规则见[天气看板说明](home-weather-dashboard.md)。

## 6. 多语言、主题与 PWA

- 主应用界面支持简体中文、English、日本語；用户输入内容不随界面语言切换而翻译。
- 支持深色/浅色主题及桌面、移动端布局。
- 通过 Service Worker 提供静态资源缓存和 PWA 能力。资源更新后需要配合缓存版本更新，并按部署流程确认线上版本。

## 7. 运行日志与系统健康检查

- 运行日志保存在当前设备的独立 IndexedDB 中，不上传云端。
- 日志支持等级、模块、日期筛选、搜索、详情、执行链路和 JSON/CSV 导出。
- 日志按保留期限与容量策略清理；日志不可用不应阻断业务功能。
- 系统健康检查覆盖本地数据可读性、日志存储、Service Worker、Supabase 只读连接和 Pages 部署记录等；无法检查与检查失败应区分。
- 不得记录密码、Token、密钥或完整业务数据。

## 8. 数据与账号边界

| 数据范围 | 存储/同步方式 | 边界 |
|---|---|---|
| 计划、工作、外语任务、整理 | 各自独立的本地分区；按模块执行 JSON 备份和 Supabase 分区同步 | 单模块操作不应覆盖其他模块 |
| 外语学习工作区 | 独立浏览器存储和 JSON 导入/导出 | 不参与四模块云同步和整体备份 |
| 公司客户、项目、跟进 | Supabase `company_records`，通过 `company-api` | 不进入计划模块数据和云端快照 |
| 天气缓存 | 独立本地缓存 | 不上传 Supabase |
| 运行日志 | 独立 IndexedDB | 仅当前设备保存，不上传云端 |

账号校验与同步机制的实现细节见 [技术手册](technical_manual.md) 和 [数据库认证设计](database_auth_design_document.md)。
