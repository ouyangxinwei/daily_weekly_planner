# 功能与系统说明

本文档按当前产品模块组织，提供当前实现的功能摘要和入口。跨语言的产品目标、业务规则、核心概念、数据生命周期和状态总表统一维护在[产品功能与业务规范](product-specification.md)；历史需求、影响分析、验收与交付记录见[开发历史档案](development-history.md)。

> 状态说明：已实现表示当前实现已建立；部分实现表示功能范围或线上验证仍有缺口；计划中/待确认不应描述为已交付。代码合并不等于线上部署成功。

## 1. 计划工作区

### 1.1 计划管理
- 支持每日、每周、每月、每年等周期计划，并提供相应随机临时计划视图。
- 支持计划新增、编辑、完成状态切换、删除、快速添加、搜索、分类筛选和排序。
- 支持 1–5 星优先级、日期与提醒、参考网站。
- 首页提供星级任务统计和快速定位入口。
- 支持分类管理、归档、回收站、恢复、永久删除和短时撤销。
- 支持分页；搜索、筛选或排序后按界面规则回到第一页。
- 支持当前模块 JSON 备份与恢复，并保留四模块整体 JSON 导出能力。

**状态：已实现。**

### 1.2 工作模块
工作事项拥有独立分类和任务状态，可进行记录管理、搜索、筛选、排序、归档、回收站、备份及云端分区管理。

**状态：已实现。**

### 1.3 外语任务模块
计划工作区内的外语任务列表与独立外语学习工作区是两套不同功能、不同数据存储，不应混为一谈。

**状态：已实现。**

### 1.4 整理模块
用于管理书籍、电子产品、软件/APP、网站等资料。采用独立列表和数据分区，不使用计划周期；支持常规列表管理、分类、搜索、归档、回收站、JSON 备份和云端分区。

**状态：已实现。**

## 2. 外语学习工作区

独立的学习工作区包含学习首页、学习内容、练习中心、错题管理、学习记录和数据管理。支持学习内容分类、学习状态、练习与笔记等能力。

- 数据保存在独立的浏览器数据分区，不与计划工作区的外语任务混用。
- 支持 JSON 导入/导出和旧数据格式兼容迁移；导入前校验并要求确认。
- 该工作区不参与计划模块的 Supabase 云端同步和四模块整体备份。
- 中、英、日文独立说明：[中文](language-learning-workspace.md) · [English](language-learning-workspace.en.md) · [日本語](language-learning-workspace.ja.md)。

**状态：部分实现。** 词汇/语法专门学习、学习统计、学习时长、间隔重复、音频、云同步和完整三语界面等能力在专项说明中仍列为未实现或待后续确认。字段、状态迁移和兼容细节以专项说明为准。

## 3. 成绩与未来工作区

首页提供「成绩」和「未来」相关入口，用于组织个人成果记录与未来规划。它们与周期计划视图分开呈现。

**状态：已实现（基础）。** V10.24 起作为计划工作区的独立模块（`personal-results:v1`、`personal-future:v1`），具备分类、归档、回收站、分页、JSON 备份和云端分区；专门的业务实体尚未定义。

## 4. 个人公司网站工作区

公司网站是慢慢计划中的独立业务工作区，目前包括：

- **客户管理：** 客户列表、搜索、业务类型/状态筛选、分页，以及客户新增、编辑、删除。
- **项目管理：** 项目关联客户，支持搜索、状态筛选、分页和 CRUD；V10.43.0 增加项目详情与手动进度百分比（0–100%）；V10.44.0 增加项目任务独立管理；V10.45.0 增加自动/手动项目进度双模式。
- **业务跟进：** 跟进记录关联客户，可选关联项目；记录跟进方式、时间、结果、下次跟进日期、备注和处理状态。
- **业务总览与工作台（V10.51–V10.54）：** 业务总览、待办中心、项目与客户概况、业务趋势与周期复盘。
- **交易收支（V10.56.0）：** 收入/支出、金额、币种、状态、日期、类别；按币种分别汇总，不做汇率换算。
- **业务文档与私有附件（V10.56.0）：** 报价、合同、发票等文档登记；交易和文档可上传私有附件（≤10 MB），通过 5 分钟有效的签名链接下载。

数据边界与 API：
- 通过 `company-api` Edge Function 访问 Supabase。
- 客户、项目、任务、跟进、交易、文档和附件元数据存放在 `company_records`，使用不同 `record_type` 区分；附件内容存放在私有 Storage Bucket `company-documents`。
- 项目和跟进的关联通过记录关系字段表达；删除存在下游引用的项目时不会自动级联删除。
- 复用慢慢计划当前登录会话；不在前端持久化密码或 service-role 密钥。
- 公司业务数据与计划模块 LocalStorage、JSON 快照及云端同步分区隔离。

状态：
- **客户管理：已实现**，用户已完成真实浏览器 CRUD 验证。
- **项目、任务、进度联动、业务跟进：已实现**，均已部署并通过用户真实浏览器验收。
- **业务总览、待办中心、项目与客户概况、业务趋势：已实现并验收**（Phase 2 于 2026-11-21 完成）。
- **交易收支、业务文档、私有附件：已实现**——V10.56.0；私有 Storage 与 company-api v6 已部署，2026-11-21 通过用户真实浏览器验收。
- **数据完整读取（V10.58.0）：** 公司业务列表、筛选、关联信息和工作台均读取完整数据；读取不完整时提示错误而不是显示部分数据；同一页面内筛选/翻页复用短时缓存，降低触发 company-api 限流的可能。

专项文档：[公司网站阶段文档](company-website/README.md)。

## 5. 首页天气看板

首页显示东京与横滨的天气信息，使用 Open-Meteo，不要求 API Key。数据有独立缓存和离线回退，不进入计划业务数据或 Supabase 同步。详细规则见[天气看板说明](home-weather-dashboard.md)。

**状态：已实现。**

## 6. 多语言、主题与 PWA

- 主应用界面支持简体中文、English、日本語；用户输入内容不随界面语言切换而翻译。
- 支持深色/浅色主题及桌面、移动端布局。
- 通过 Service Worker 提供静态资源缓存和 PWA 能力。资源更新后需要配合缓存版本更新，并按部署流程确认线上版本。
- 独立工作区的语言覆盖范围可能与主应用不同，不能仅凭主应用支持三语推断所有模块均已完成三语化。

**状态：已实现（按主应用范围）；独立工作区覆盖范围见各专项文档。**

## 7. 运行日志与系统健康检查

- 运行日志保存在当前设备的独立 IndexedDB 中，不上传云端。
- 日志支持等级、模块、日期筛选、搜索、详情、执行链路和 JSON/CSV 导出。
- 日志按保留期限与容量策略清理；日志不可用不应阻断业务功能。
- 系统健康检查覆盖本地数据可读性、日志存储、Service Worker、Supabase 只读连接和 Pages 部署记录等；无法检查与检查失败应区分。
- 不得记录密码、Token、密钥或完整业务数据。

**状态：已实现。** 具体技术设计见 [运行日志专项说明](runtime-logging.md)。

## 8. 数据与账号边界

| 数据范围 | 存储/同步方式 | 边界 |
|---|---|---|
| 计划、工作、外语任务、整理 | 各自独立的数据分区；按模块执行 JSON 备份和 Supabase 分区同步 | 单模块操作不应覆盖其他模块 |
| 外语学习工作区 | 独立数据分区和 JSON 导入/导出 | 不参与四模块云同步和整体备份 |
| 公司客户、项目、任务、跟进、交易、文档 | Supabase 公司业务 API | 不进入计划模块数据和云端快照 |
| 公司附件文件 | 私有 Supabase Storage（经 company-api 签名 URL） | 不公开、不进入计划模块备份 |
| 天气缓存 | 独立本地缓存 | 不上传 Supabase |
| 运行日志 | 独立本地诊断存储 | 仅当前设备保存，不上传云端 |

账号校验与同步机制的当前实现细节见[技术手册](technical_manual.md)和[数据库认证设计](database_auth_design_document.md)；跨语言安全与业务原则见[产品功能与业务规范](product-specification.md)。
