# 外国語学習ワークスペース V1.0.0

慢慢计划アプリ内に独立した外国語学習ワークスペースを追加します。TOEIC Study System の画面構成や学習操作を参考にしますが、ソースコード、データベース、データ構造は再利用しません。

## ナビゲーション
既存の「外国語学習」モジュールを選択して入ります。学習ホーム、学習コンテンツ、練習、間違い管理、学習履歴、データ管理を提供します。他のモジュールを選択すると従来の画面に戻ります。

## V1.0.0 の機能
- 英語、日本語、ドイツ語、ロシア語、その他の学習内容を追加・編集。
- 種類：語彙、文法、読解、リスニング、問題、その他。
- 検索と言語・種類による絞り込み。
- 未習得コンテンツをランダム表示し、答え・解説の表示／非表示に対応。
- 「習得済み」「復習が必要」を記録し、学習履歴を作成。
- 間違い一覧、JSON エクスポート／インポート（検証と確認付き）。
- 独立 LocalStorage キーを使用し、旧外国語データや Supabase にはアクセスしません。

## データと安全性
personal-language-study-workspace:v1 に schemaVersion、items、records、settings を保存します。既存モジュールの保存キー、バックアップ、Supabase 領域は変更しません。旧 personal-language:v1 データは削除しません。V1 データは現在のブラウザー内に保存されます。インポート上限は 5 MB です。

## 制限事項
カード形式の自己学習であり、本格的な模擬試験エンジンではありません。自動採点、セット試験、音声アップロード、間隔反復、クラウド同期は未実装です。画面文言は主に中国語です。

## 手動受け入れ
1. 外国語学習を開き、計画一覧が学習画面に切り替わることを確認。
2. 英語の語彙と日本語の文法を追加し、更新後も残ることを確認。
3. 検索と言語・種類の絞り込みを確認。
4. 答えを表示し、習得済み／復習が必要を記録。
5. 間違い管理と学習履歴を確認。
6. 内容を編集し、状態と履歴が保持されることを確認。
7. JSON をエクスポートして再インポート。
8. 計画／仕事／整理へ切り替えて戻り、データが分離されていることを確認。
9. モバイル幅で画面を確認。
