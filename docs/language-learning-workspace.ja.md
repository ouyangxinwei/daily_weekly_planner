# 外国語学習ワークスペース V2.0.0（アプリ V10.35）

慢慢计划アプリ内の独立した外国語学習ワークスペースです。TOEIC Study System の画面構成や学習操作を参考にしますが、ソースコード、データベース、データ構造は再利用しません。詳細は本フォルダーの V10.35 要件・影響分析・受け入れ文書（中国語）を参照してください。

## ナビゲーション
- 上部の「計画ワークスペース／語学学習ワークスペース」で切り替えます。語学学習ワークスペースではモジュールバーと計画領域を隠し、テーマ、表示言語、アカウント、システムツールは使用できます。
- 現在のワークスペースは `personal-planner:active-workspace:v1` に保存され、再読み込み後に復元されます。`index.html` の `<script data-workspace-boot>` が早い段階で `html[data-workspace]` を設定し、計画一覧のちらつきを防ぎます。
- 学習ホーム、学習コンテンツ、練習センター、間違い管理、学習履歴、データ管理。カードの「学習」で詳細画面を開きます。
- 計画ワークスペースの「語学タスク」は元の外国語タスク一覧（`personal-language:v1`）で、本ワークスペースとは独立しています。

## 学習状態
未学習 →（開く）学習中 → 完了／要復習／習得済み、習得済み →（再学習）学習中。状態は学習操作でのみ変わり、操作ごとに学習履歴を作成し `lastStudiedAt` を更新します。編集では状態は変わりません。練習は習得済みを出題せず、要復習を優先します。

## データ（schemaVersion 2）
キー `personal-language-study-workspace:v1` に `items`（単元、難易度、状態、最終学習日時）、`records`（操作と操作後の状態）、`notes`（個人メモ、3000 字以内）、`settings` を保存します。コンテンツを削除しても履歴とメモは保持します。

## V1 からの移行
V1 データは自動移行され、移行前に元の文字列を `personal-language-study-workspace:v1:pre-v2-backup` に保存します（上書きしません）。状態の対応：new→not_started、mistake→review、mastered→mastered。認識できないデータは読み取り専用で開き、書き戻しません。データ管理から元データを書き出せます。

## インポート／エクスポート
schemaVersion 2 と `moduleType: "language-workspace"` で書き出します。インポートは V1／V2 に対応（上限 5 MB、検証と確認あり）。ネットワーク通信は行わず、クラウド同期の対象外です。

## ロールバック
V10.34 は V2 データを読めず、操作すると空データで上書きします。ロールバック前に JSON を書き出し、後で pre-v2 バックアップキーまたは書き出したファイルから復元してください。

## 制限
語彙・文法ページ、統計、学習時間、間隔反復、音声、クラウド同期、完全な多言語 UI は今後のバージョンで対応予定です。
